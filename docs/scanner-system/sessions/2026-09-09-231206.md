For an offline prelabeling experiment, the recommended first candidate is **SAM 3**. Meta documents text/exemplar/box/point prompting and segmentation of multiple instances of a concept. That makes a prompt such as “trading card” worth testing for proposing all physical cards in a photo. This is a proposed application, not a measured card-accuracy result. The official implementation lists a CUDA GPU, Python 3.12+, and PyTorch 2.7+; the checkpoint is access-gated. [Official SAM 3 repository](https://github.com/facebookresearch/sam3), [model card](https://huggingface.co/facebook/sam3).

**SAM 2.1 Hiera Large** is an available fallback for refining existing detector boxes, with point/box prompts and multi-object segmentation examples. Its Hugging Face metadata reports an ungated checkpoint with 224,447,154 parameters and its model card lists Apache-2.0. [Official model card](https://huggingface.co/facebook/sam2.1-hiera-large). These are model availability checks, not an integration or inference run.

The repo already has MobileSAM adapters in `mobile-apps/ios/scripts/session-labeling/alt_detectors.py`, but some paths prompt only the strongest detected box and fall back from a contour to a minimum-area rectangle. A larger model should run once per full photo with all-instance discovery or once per distinct detector prompt, retain its masks, and fit conservative four-corner draft proposals only when supported. A segmentation mask alone does not establish the complete hidden outline, printed-top orientation, or reviewed stacking. Preserve those uncertainties and keep human-saved outlines authoritative.

Recommended trial: use a small diverse set of previously reviewed development photos, covering isolated, rotated, sleeved, and overlapping cards; measure missed/extra cards, accepted proposals, and correction effort against the current detector/MobileSAM baseline. Review raw masks beside proposed quads in the studio before expanding preprocessing. The reserved 75-photo session should remain separate from model training and tuning.
