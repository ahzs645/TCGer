The editable outline controls the crop. Source polygon in More tools adds the original reference as a second line for comparison.

Every queued card starts as a dashed amber outline you can move: drag any handle onto the real corner. A changed card is a draft until you press C to confirm. Scroll to zoom, drag empty space to pan, double-click or 0 to reset. If a box already fits, check the preview and press C to confirm it. R rotates a card's corner order by a quarter turn; set Printed top points once per page so seeded boxes start with the right orientation, and check the thumbnails below the photo: every card should appear upright when its orientation is known. For a skewed card press D and click TL → TR → BR → BL of the printed card. O marks a corner hidden by another card; corners beyond the photo edge are marked automatically. S skips a card you cannot label. N next card, 1–4 pick a corner, arrows nudge (Shift ×5), Enter saves confirmed cards and moves on. Save also stores unconfirmed edits as drafts on the local server. Use Reflected padding to skip artificial card fragments repeated along an image border. With Approve on Save / Next enabled, Save frame, Next, Save & next, or Enter approve and save every unskipped outline on the page. N approves and saves the selected card before advancing. Turn it off to require C for each card. Skipping excludes human corners; the original box remains available as supervision. Back up browser drafts before moving to another browser.
