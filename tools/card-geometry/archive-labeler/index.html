Every queued card starts as a dashed amber outline you can move: drag any handle onto the real corner. Scroll to zoom, drag empty space to pan, double-click or 0 to reset. If a box already fits, press C to accept it. R rotates a card's corner order by a quarter turn; set Printed top points once per page so seeded boxes start with the right orientation, and check the thumbnails below the photo: every card should appear upright there. For a skewed card press D and click TL → TR → BR → BL of the printed card. O marks a corner hidden by another card; corners beyond the photo edge are marked automatically. S skips a card you cannot label. N next card, 1–4 pick a corner, arrows nudge (Shift ×5), Enter saves and moves on. Untouched boxes are never saved as labels; nothing here changes the dataset.
