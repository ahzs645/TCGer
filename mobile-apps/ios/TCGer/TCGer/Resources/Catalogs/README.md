# iOS catalog resources (generated — not committed)

This directory holds the per-game offline catalog packs bundled by the iOS app.
Generated `manifest.json` and `*.pack.json` files are large, reproducible, and
gitignored.

## Regenerate

```bash
bunx tsx backend/src/scripts/build-catalog-packs.ts --sync
```

The canonical generated copies are written to `data/catalog/`; `--sync` refreshes
the web and iOS resources together.

Pokémon TCG Pocket is included inside the Pokémon pack and identified by the
TCGdex series value `tcgp`. It intentionally does not use a separate `TCGGame`
case, because persisted collections and server APIs use `pokemon` as the shared
game identifier. Pocket-only card rules and booster metadata are generated by
the same pack builder and consumed offline through `CatalogStore`.
