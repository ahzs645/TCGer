# Card-back sources

These images are local UI fallbacks for identifying a card's game when its
front image is unavailable. All game names, artwork, and trademarks belong to
their respective owners; TCGer is not affiliated with them.

- `onepiece.jpg`: standard blue One Piece Card Game back, from
  [BoardGameGeek image 6974116](https://boardgamegeek.com/image/6974116/one-piece-card-game).
- `lorcana.png`: standard Disney Lorcana back, from
  [BoardGameGeek image 7940425](https://boardgamegeek.com/image/7940425/disney-lorcana).
- `dragonball.jpg`: clean rendering of the shared Dragon Ball Super Card Game
  non-Leader back, from
  [DragonBallProxyHouse](https://www.deviantart.com/dragonballproxyhouse/art/Card-Back-Bandai-DBS-973699425).
